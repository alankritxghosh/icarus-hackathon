  | design (propose, revise, edit) | yes, 405 | brief ≤ 1,500 chars, edit ≤ 400, ≤ 60 rooms | no; the body is parsed as JSON whatever the header says | daily budget only (P1-5) |

  Error messages are plain sentences. A fake job id returns "the renderer failed" and nothing internal leaks.
- **Denial of wallet:** the daily cap is checked **before** each call and charged after, so concurrent calls can overshoot it (noted in `META_CREDITS.md`). Modal is reachable only with the bearer token, which the browser never sees. Render spend is bounded by `max_containers=2` at a time, but queued jobs are not limited: 4 bakes per minute per IP at about 4–5 GPU-minutes each could build a queue.
- **Untrusted input:**
  - Model text is rendered as React text. There is no `dangerouslySetInnerHTML` or `innerHTML` in `apps/web/src`.
  - Prompt injection can only produce operations from the closed `EditSchema` set, which `applyEdit` still measures.
  - PDF parsing is poppler with 60 s subprocess timeouts and an 8 MiB cap; no zip-bomb test was run.
- **Headers:** `/api/*` sends no CORS headers, so cross-origin JSON requests fail preflight (`OPTIONS` returns 405). A `text/plain` form post would still be parsed, though `curl` can call the API anyway. There is no CSP and no `X-Frame-Options`, so the site can be framed (low impact: no accounts).

## Investor view (plain language)

1. **Problem, for whom.** An office manager or founder planning a 10–60-person fit-out who does not yet want to pay a designer. Today they use a broker's floor plan, a designer's first sketch or a spreadsheet of seats. Icarus gives a measured plan, a walkable model and plain-word changes in about a minute.
2. **What is defensible.** "The model proposes, the engine decides" is visible: refusals name the rule that blocked the change, collateral moves are named, and the build steps say how many model ideas were kept. That is a product behaviour, not a moat yet. The moat would be the engine's rules and evidence, which are still internal.
3. **What is measured, and what is not.** Measured: edit reading 20/20 on 20 sentences (3 Nov, local Worker); the design loop's plan cost 6.7% lower over 12 briefs (better on 4, worse on 4, level on 4); exports open in external tools.

   Not measured: any independent designer or architect review, a second device, real users, and the cost or quality of a real fit-out.

   **Stronger than the evidence:**
   - "6.7% lower cost" is an internal plan score, not money, and is a 4–4–4 split. Say "internal plan score".
   - "20/20" is 20 sentences. Today one of the three scripted sentences was refused on the live layout.
4. **Next paid milestone.** An editable plan a designer can take further, with an independent review of one real brief. The README names the limits honestly (rectangular single-floor offices, one browser) but does not name a paid milestone.
5. **A buyer moment in the first 30 seconds.** With the revised script, yes: a sentence becomes a furnished 3D office by about 0:45. The bare homepage alone is not a buyer moment.
