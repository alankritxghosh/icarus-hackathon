# Open gates to the north-star journey

31 October 2026. Checked means observed or tested on this worktree, not generally proven. This is the single checklist for the demo cut and the larger product goal. A source or a test is named beside each result. No item below authorizes a push, deploy, paid call, publication or submission.

## Demo path: a brief to a revised, usable concept

- [x] **Report an incomplete brief honestly.** The offline 12-person starter places 5 of 12 desks in its stated 14 × 10 m shell and says “Made a draft”; the reply names the shortfall. `apps/web/src/completion.ts`, `test/recovery.test.ts`, local browser run.
- [x] **Offer a measured recovery without changing the user's facts silently.** The larger-shell option was evaluated at 16.5 × 11.5 m, places 12 of 12 desks and one booth, and is applied only after the explicit chat request. Undo restores the original. `apps/web/src/recovery.ts`, `test/recovery.test.ts`, local browser run.
- [x] **Check the scene independently of its furnishing report.** Completion compares requested room IDs with plan rooms and counts desk and phone-booth objects in the 3D scene; mutation tests remove an object to confirm a false complete claim is blocked. `apps/web/src/completion.ts`, `test/recovery.test.ts`. This does not independently judge usable clearances.
- [x] **Make a normal prompt edit and disclose collateral movement.** “Move the kitchen east” moved its centre from 7.5 m to 10.5 m and said Meeting room 1 also shifted 3 m. The saved conversation and project reopened after reload in the local browser. Existing `editByWords` and core edit tests cover refusal and locks.
- [x] **Export files that independent tools open.** The recovered DXF passed `ezdxf audit` with zero errors (67 entities); its extents matched the shell plus wall thickness. The 37 MiB GLB imported into Blender 5.2.1 with the same mesh, object and vertex counts as the 121 MiB version. `docs/decisions/glb-export-textures.md`. DXF is an editable 2D plan; GLB is a visual mesh scene.
- [x] **Run the whole path at desktop, 390 px and 320 px on the current candidate.** Fresh, isolated headless Chrome contexts at 1440, 390 and 320 px built the 12-person starter, reported 5/12, accepted the measured larger shell, reached 12/12, edited the kitchen with collateral disclosure, switched Plan/Walk/3D, undid the edit, reloaded, reopened the saved project through Projects, and triggered both GLB and DXF downloads. All three had no page errors and no horizontal overflow. Representative screenshots: `docs/qa-evidence/2026-10-31-{desktop-final,390-plan,320-final}.png`. The desktop and 390 px files were saved; the 320 px GLB download was observed but its duplicate was not retained after local disk space ran low. This is browser emulation on one Mac, not a real-device or second-GPU test.
- [x] **Independently audit unintended changes across the 158-request edit corpus.** An audit comparing before/after room rectangles (0.25 m centre or dimension threshold) initially found 321 changes that were not individually named. Edit replies now name every materially moved or resized room; removing a meeting room also names the remaining rooms that were renumbered and re-laid out. The repeat audit found zero silent changes and zero mutations after a refused or already-satisfied edit. This is still a geometry audit, not an external design-quality judgment. `apps/web/test/eval/edit.eval.test.ts`; run with `EDIT_EVAL_OUT=/tmp/icarus-edit-audit-final.json pnpm exec vitest run apps/web/test/eval/edit.eval.test.ts`.
- [ ] **Record one clean three-minute demo from a fresh session.** No hidden manual repair, unsupported prompt or stale saved project. Preserve the brief, actual reply and exported files with the run.

## Attached plans

- [x] **Support a narrow edit on a known vector plan.** A generated two-room filled-wall PDF can move one straight partition by 500 mm, rebuild rooms and doorway, save, reopen and undo. `packages/spatial/test/drawingEdit.test.ts`, `docs/decisions/edit-drawing-partition.md`, earlier browser run.
- [ ] **Read representative real vector plans reliably.** The recorded real A3 sheet closed only 5 of 23 labelled rooms; the current importer still requires filled wall shapes and a readable scale or an explicit scale. Assemble at least three permitted real sheets with hand-counted rooms, doors and dimensions, then measure missing and inferred geometry. This is a product gate, not a fixture-only test.
- [ ] **Edit more than one unambiguous straight partition.** Irregular junctions, ambiguous walls and older saved drawings without source shapes are refused. Broaden operations only with drawing evidence tests that show unrelated walls, openings and rooms stay put. Structural status remains unknown.

## Release confidence and external dependencies

- [ ] **Get an independent workplace designer or architect to review at least one brief and its revision.** Ask whether seats, circulation, room sizes and handoff are useful without showing Icarus's score. The current concept thresholds are internal assumptions.
- [x] **Validate the current GLB independently and record its remaining warning.** The official Khronos glTF Validator 2.0.0-dev.3.10 found zero errors, 73 `MESH_PRIMITIVE_GENERATED_TANGENT_SPACE` warnings and 135 informational `UNUSED_OBJECT` texture-coordinate notices in the 37 MiB file. Blender also opened it. The missing tangents affect normal-map shading fidelity in some renderers. An earlier tangent-generation trial made the file about 100 MB without clearing the warnings, so this remains a documented quality limit, not a clean-warning claim. Report: `/tmp/icarus-current-glb-report.json`.
- [ ] **Check the current candidate on another GPU and with keyboard-only controls.** The realistic renderer has been measured on one Apple M1; the current mobile/browser changes need a fresh manual accessibility pass.
- [ ] **Smoke-test the live Meta model route and record what it contributes.** No `MODEL_API_KEY` is present in this worktree's environment or `apps/edge/.dev.vars` as of this audit. Use an authorized key, credits and explicit spend cap when available; keep the rules-only journey functional. See `docs/META_CREDITS.md`. Voice input is not yet built.
- [ ] **Review provenance, secrets, copy and the final submission package.** Then obtain the founder's explicit approval before push, public release, deployment or paid resource creation, per `CLAUDE.md`. The repo lists the submission deadline as 4 November 2026, 9 PM EDT.

## Gates beyond the demo cut

- [ ] **Share and resume across devices.** Projects and learned preferences currently live in one browser; there is no identity or synced project store.
- [ ] **Give another designer a semantically editable 3D project.** A GLB can be edited as meshes in Blender, but it does not preserve Icarus rooms, constraints or prompt history. DXF carries the 2D plan. Choose and validate a professional interchange format before promising this.
- [ ] **Expand the modelling domains.** L-shaped and multi-floor offices, non-rectangular parts, photo geometry and general “prompt anything” creation need separate solvers and acceptance tests. They are not claims for this release.
