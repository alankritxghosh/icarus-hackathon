# Icarus

Describe or photograph a physical thing, and get a real, editable CAD model with every assumption on the table.

Icarus turns words, a photo and your voice into a constrained parametric assembly, builds true B-Rep solids, exports STEP and GLB, checks its own output with independent readers, and lets you change the design by talking to it. It is built for the Meta Global AI Developer Hackathon (Indie developer track) on Muse Spark, SAM 3.1 and Muse Voice Transcribe.

Engineering output is **concept geometry only**. Structural, thermal, propulsion, controls, manufacturing, flight and certification readiness all fail closed until independent, qualified evidence is attached. Icarus never says otherwise.

## Provenance

This repository was created on **26 October 2026, after the hackathon kickoff (12:00 PM EDT)**, and every line of code in it was written during the hackathon. The Git history is unedited, so `git log` shows exactly what was built and when.

The idea is not new to this repository: the author explored a similar product in an earlier private prototype before the hackathon. That prototype is **not part of this repository**, no code or tests were copied from it, and nothing in it used a Meta model. What carried over is the problem framing and the lessons learned, not the code.

Code in this repository was written with the help of an AI coding assistant (Claude Code) under the author's direction.
